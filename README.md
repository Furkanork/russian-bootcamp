# РЫВОК: Russian A2 → B1 bootcamp

A single-page, phone-friendly study site for taking Russian from A2 to B1 in eight weeks, built on the 80/20 (Pareto) principle and styled as a Soviet propaganda poster.

**Open it:** once GitHub Pages is on, the site is at `https://<your-username>.github.io/russian-bootcamp/`.

## What's inside
- 80/20 coverage chart showing where you are
- 8-week plan (48 tasks) with ranks from Октябрёнок to Герой труда
- Daily-norm tracker (56 days)
- Alphabet with pronunciation rules
- 19 grammar tables: cases, pronouns, adjectives, aspect, motion verbs, imperative, который, если/чтобы and more
- 1,077-word frequency list with a text-coverage meter
- Flashcards, a case-ending drill, a reading text, 50 phrases and a 35-question level check

Everything is in `index.html`. Progress is saved in your browser only.
